1. Voice Models: The Core of Fina

Fina needs two types of "brains" to talk and listen. While Fina downloads a basic version on first start, for the best experience you should set up high-quality offline models.

A Listen: Vosk Recognition Model

This allows Fina to hear you without an internet connection.

  • Choosing the model: We recommend the Large models (around 1-2GB) for maximum accuracy.
  • Where to download: Go to Vosk Models.
  • Installation:
    1. Download the model for your language (e.g., vosk-model-en-us-0.42).
    2. Unzip it inside: ~/.config/Fina/model/
    3. In Fina's Settings, go to Intelligence Domain > Path Options and paste the folder path.

B Speak: Piper Speech Model (TTS)

This is how Fina's voice sounds. You can have multiple voices!

  • Downloads: Get .onnx and .json files from the Piper Repository.
  • Storage: Place all voice files in: ~/.config/Fina/voice_models/
  • Switching: Once files are there, you can simply tell Fina: "Fina, change your voice".

Fill the forms with your API keys and click "Save".

3. Smart Home (IoT)

Fina can control TVs, lights, and AC units by scanning your local network.

Pro Tip: Room Assignment
When a device is detected, click the Pencil icon to assign it to a "Room" (e.g., 'Kitchen' or 'Living Room'). This prevents Fina from getting confused if you have multiple TVs.
